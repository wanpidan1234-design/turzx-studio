# Claude 与 cswap 屏幕

控制台提供「Claude 订阅」和「Claude 多账号」两个页面，支持 1280×720 横屏和 720×1280 竖屏。多账号页按真实账号数量适配 1–5 个账号。0 个账号显示空态。每个账号显示名称、套餐、当前账号标识，以及 5h、7d、Fable · 7d 三个额度窗口。单账号卡片另显示脱敏邮箱。

所有 Claude 数值和进度条表示「已使用」，直接使用服务端 `utilization` 百分比，不再取补数。Fable 使用 `seven_day_fable`，不代替总周额度。未知额度显示破折号。

每个窗口只显示一行相对重置时间，例如「2小时25分后重置」。缺失、无效或已过去的时间留空，不推算下一次时间。旧采样仍可使用已有的未来重置时刻计算倒计时，数值保留弱化样式。页面不显示上次读取提示、绝对日期、时区、计划时段、调度说明或刷新提示。

单账号页同样包含 5h、7d、Fable 三个窗口，其他模型额度仅在来源返回有效值时显示已使用比例。背景使用用户选定的 v3 Claude 01 从容站姿，默认使用图片亮度 112%、色彩浓度 85%、淡化 12% 的浅亮处理，实体输出沿用用户确认的全局位置/色调校准和 BRG 色序。

横屏 1 个账号使用大卡片，2–3 个账号并列，4–5 个账号使用行表；竖屏采用纵向卡片和底部人物构图。超过 5 个账号时显示前 5 个；当前账号若不在其中，则占用第 5 个位置，并显示总数。实现说明见 `design/designer-handoff/implementation.md`。图片来源和提示词见 `design/claude/character-brief.md`。

## 使用

启动本项目的 `server.py`，打开 `http://127.0.0.1:8765/`，选择页面。「刷新账号额度」通知本机 cswap 调度服务读取最新额度。查看页面本身不触发模型推理。

cswap 项目单独位于 `/Users/zhy/Github/cswap`。其调度服务负责账号凭据、额度请求、每日最小调用和 99% 切换。调度命令与安装方式以该项目的调度文档为准。

## 数据

本项目只读取 cswap 生成的 `schedule-status.json`。macOS 默认路径为 `~/.claude-swap-backup/schedule-status.json`；Linux 使用 XDG 数据目录的 `claude-swap/schedule-status.json`。可通过 `TURZX_CSWAP_STATUS_PATH` 指定路径。

服务每 2 秒读取本地快照。手动刷新写入同目录的 `schedule-refresh.request`，由 cswap 执行网络读取。网络请求仍遵循 cswap 的限流和退避规则。

`/api/claude` 和 `/api/state` 的 `claude` 字段只含白名单字段。邮箱经过脱敏。屏幕服务不读取 OAuth 凭据，也不向浏览器传递 token。来源缺失、读取失败、过期和未知额度分别显示。未知值不会转换为零或无限。

5 小时、7 天、Fable 与其他模型数据均展示「已使用」，直接读取服务端已用百分比。不推算调用次数、账单金额或续费日期。

## 计划时段与实际窗口

三个账号按 cswap 原编号对应北京时间 07:00–12:00、12:00–17:00、17:00–22:00。计划时段是本机调度目标。实际窗口由 Anthropic 服务端控制，页面单独显示服务端返回的重置时间。

最小模型调用能够启动空闲窗口，但不能提前重置已有窗口。账号已用额度达到 99% 时，调度服务切换到可用账号；提前启用备用账号可以使其实际窗口偏离计划时段。屏幕不会将计划时段显示为已确认的服务端窗口。

macOS 全局账号切换与已运行的 Claude Code 会话读取凭据之间存在延迟；独立的 `cswap run` 会话有自己的账号上下文。详见 cswap 项目说明。

## 图片调节

管理页选择 Claude 或 OpenAI 场景，在「显示 → 背景图片」调整图片亮度（80–140%）、色彩浓度（50–120%）和淡化（0–50%）。桌面设置栏直接显示此分组。松开滑块后自动保存，预览和副屏读取同一组参数。重启服务后保留设置。

「推荐浅亮」应用 112%、85%、12%。「恢复原图色彩」应用 100%、100%、0%。调节只作用于背景图片，不修改文字、额度进度条、USB 色序和位置校准。OpenAI 原有背景透明度继续单独生效。


## 选择背景

管理页「显示 → 背景图片」提供三张新版人物缩略图：01 从容站姿、02 侧望凝思、03 抬手相伴，以及纯色背景。点击后自动保存。Claude 订阅和 Claude 多账号共用选择，横竖屏自动适配。原有图片亮度、色彩浓度和淡化参数继续生效。

`claude_background` 仅接受 `stand`、`thought`、`greeting`、`none`。旧配置默认使用 `stand`。OpenAI 背景独立保存，选择入口也在「显示 → 背景图片」。
