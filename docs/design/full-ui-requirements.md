当前页面按用户参考截图使用独立卡片。请保留信息分组和阅读顺序，并为不同数量重新设计布局。不要把 3 张卡片直接缩成 5 张。

| --- | --- |

| 身份 | 账号名称、当前账号标识；顺序稳定，切换当前账号不让全部卡片换位 |

计划时段不能代替实际窗口。实际重置时间由服务端决定。剩余 ≤ 1% 对应已用 ≥ 99%，可以显示低额度状态，但不能仅凭此断言已成功切换账号。

## 完整操作流程与异常状态

设计稿需包含可连通的交互原型，覆盖以下流程：

1. 打开控制台 → 获取状态 → 选择场景 → 查看横竖预览 → 开始投屏 → 停止投屏。
2. 选择方向、帧率、颜色修正与亮度 → 显示变更反馈；未连接时呈现亮度禁用原因。
3. 开启全局换页 → 调整停留时间 → 关闭换页并固定场景。
4. 进入 OpenAI → 切换子页面/额度分组 → 选择背景与透明度 → 刷新 → 查看部分来源失败；区分 3 层轮播/分页。
5. 进入 Claude 当前账号/多账号 → 识别当前账号 → 查看 1–5 账号 → 刷新 → 处理旧数据或未连接。
6. 进入动画 → 切换 4 个效果 → 调速、细节、时钟 → 暂停/继续 → 换一幅。
7. 开始专注 → 切换页面 → 暂停/继续 → 完成/重置；编辑便签 → 保存成功或失败。
8. 展开设备说明 → 加载成功或失败 → 收起/重试；访问官方来源。
9. 设备未接入、被占用、传输失败、连接恢复；工作台服务中断、请求超时；恢复后的状态与操作可用性。

通用组件至少覆盖：默认、悬停、键盘焦点、选中、禁用、加载中、成功、错误。提供下拉菜单展开态、滑块反馈、开关、文本输入、字数限制、提示条、折叠区域和导航的规则。

## 数据与文案规则

- 所有真实数据、未知数据、旧数据、示例数据必须区分。
- 未接入不等于 0；剩余 0% 和 100% 都是有效值；缺失用「—」及说明。
- 重置时间缺失时不推算。已到重置时刻但数据未更新，显示「等待更新」，不补满额度、不显示负数倒计时。
- 计划时段、实际额度窗口、订阅账期、续费时间分别命名。
- GPU、温度、功耗、风扇等不可读时保留缺失状态。磁盘与内存容量使用 GiB；网络速率使用 B/s、KiB/s、MiB/s。
- 网卡活跃不等于互联网可用。请求帧率不等于实际发送 fps。成功 ACK 不等于实物画面已验收。
- 除世界时钟外，账号窗口、计划、重置和续费显示使用北京时间；伦敦、纽约按时区规则处理夏令时。
- 邮箱保持脱敏；长名称、硬件名和错误说明有截断规则；核心数值与时间不得因截断丢失。
- 页面不出现 `cswap` 字样。内部代码标识仅用于开发对照，不作为产品文案。

## 视觉方向与背景

整体使用一致的栅格、间距、字体层级、按钮、表单和状态语言。不同场景可以使用适合的明暗与强调色，但不能像互不相关的产品。

订阅场景采用简洁浅色。Claude 使用现有橙发、金花黑缎带、奶油披肩、黑裙形象。画风和位置参考 OpenAI 龙娘：细线条、柔光、浅色留白；横屏靠右，竖屏靠右下。不要恢复旧针织背心人物。

背景与数据一起设计。人物面部和发饰不被核心面板遮挡。账号数量增加时调整构图、人物大小或裁切，不把所有数据直接压在头发和衣服纹理上。必须覆盖 OpenAI 的 4 个背景选项与透明度端点；不要求所有页面都增加人物插画。

数字使用等宽数字特性，更新时不跳位。界面避免高噪声背景、复杂阴影和过多装饰。低额度与异常不能仅依赖颜色。文字与背景建议达到 4.5:1 对比度。以原生小屏尺寸检查清晰度，不以放大的设计稿代替实测阅读。

## 验收标准

1. 11 个场景、3 个 OpenAI 子页面、4 种动画、全部现有控制台设置都有对应设计。
2. 40 个副屏主画板和至少 10 个控制台画板齐全，附状态与交互规范。
3. 1–5 账号同页读取所有 5h、7d 额度和重置时间；5 账号不靠滚动、分页或缩成难读小字。
4. 控制台所有功能在桌面和窄屏均可访问，设置分组清晰。
5. 当前账号、旧数据、未知、耗尽、断连、投屏停止和暂停动画有明确差异。
6. 核心信息无遮挡、无越界，背景适配人物与数据；普通页面不堆四角信息。
7. 设计没有虚构当前未接入的数据或尚未实现的设置。
8. 控件可用 HTML/CSS/Canvas 实现，并可映射回项目现有行为。
