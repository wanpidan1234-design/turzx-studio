## 管理页

桌面采用导航、预览、设置三栏。窄屏采用横向场景选择和显示、场景、专注·便签、设备四个页签。设置继续调用现有本地 API。

服务、设备、输出分别显示状态。运行信息可折叠。保留亮度、方向、发送帧率、色序、自动换页、订阅背景与透明度、订阅轮播、刷新额度、动画设置、专注计时、便签和设备资料。

便签区显示未保存、保存中、已保存、保存失败。定时读取不会覆盖未保存草稿。输出请求期间禁用重复操作。断线后提供重试入口。

## 对设计样例的必要调整

- 用户确认的 Claude “已使用”语义优先于设计稿里的剩余示例。所有数值直接读取 `utilization`。
- 重置时间仅一行相对倒计时。缺失、无效和已过期时间留空。省去零值单位以保持 18 px 文字单行可读。
- Claude 不显示账号服务项目名、时区、计划时段、上次读取时间和刷新占位文案。
- 人物使用用户选定的 v3 01 从容站姿。浅色处理可在管理页调节，并保存到本地偏好。竖屏将人物置于数据下方；不让卡片遮挡面部。
- 设计包中的账号、额度、硬件参数和媒体内容均为示例。运行页继续读取真实 API。
- `source/*.dc.html` 依赖设计工具模板运行时，因此在原有 JS/CSS 内实现布局，不引入模板中的模拟数据。
- 字体为本地 Inter Variable；字体缺少的中文字符使用系统中文字体。

## 输出约束

本轮不改 USB 协议。保留用户确认的 BRG 色序、原生 X=-60 偏移、gamma=1、saturation=1。亮度保持 100。每张输出保持 720×1280、RGBA、alpha=255、PNG color type 6、小于 1 MiB。
